# 📚 Peta Navigasi Dua Skenario Naskah Draf Proposal

Folder ini menyediakan **dua versi draf lengkap Bab I s.d. Bab III** untuk memudahkan konsultasi dengan Dosen Pembimbing (**Pak Hafiz Budi Firmansyah, S.Kom., M.Sc.**):

---

## 🧭 Perbandingan Skenario

| Parameter | Folder `01-Skenario-Murni-Komputasional` | Folder `02-Skenario-Dual-Evaluation-User-Study` ⭐ |
| :--- | :--- | :--- |
| **Deskripsi** | Pendekatan evaluasi komputasional objektif pada dataset benchmark DEAM menggunakan metrik matematis ($\mathcal{S}, \mathcal{E}, \mathcal{B}$) tanpa kuesioner manusia. | Pendekatan evaluasi ganda (*Dual Evaluation Framework*): metrik komputasional di GPU dipadukan dengan pengujian kuesioner pengguna (*Blind A/B Listening Test* 30s klip, $N \ge 30$). |
| **Rumusan Masalah** | 3 butir (Desain Pipeline, Komparasi Smoothness/Evenness vs Gaur, Kuantifikasi Dinamika DEAM). | 4 butir (RM 1–3 + RM 4: Korelasi metrik objektif dengan respon perseptual pendengar). |
| **Tujuan Penelitian** | 3 butir (Arsitektur PyTorch GPU, Reduksi $\mathcal{S} \ge 15\%$, Penurunan Boundary Jump Cost). | 4 butir (TP 1–3 + TP 4: Uji signifikansi Wilcoxon Signed-Rank $p < 0.05$ & MOS kuesioner). |
| **Batasan Penelitian** | Butir 4 secara eksplisit **mengecualikan** pengujian persepsi manusia. | Butir 4 membatasi pengujian manusia pada **klip transisi sambungan 30 detik pada $N \ge 30$ responden**. |
| **Cakupan Bab 3** | Subbab 3.1 s.d. 3.5 (Alur, Prapemrosesan, Pipeline, Lingkungan, Metrik Matematis). | Subbab 3.1 s.d. 3.6 (Memuat tambahan **Subbab 3.6 Metode Pengujian Subjektif User Listening Study**). |
| **Beban di Sempro** | Selesai 100% pada proposal. | Metodologi & instrumen kuesioner selesai di proposal; pengambilan data responden dieksekusi saat TA 2. |
