# 💬 Subfolder: 04-Tanya-Jawab

Subfolder ini menyimpan seluruh catatan tanya jawab belajar (*learning Q&A*) antara pengguna dan agen AI.

## Aturan Pencatatan
1. **Pengelompokan per topik:** Satu berkas per topik besar dengan format nama `QA-<Nama-Topik>.md`.
2. **Pertanyaan lanjutan:** Jika ada pertanyaan baru pada topik yang sama, tambahkan bagian `## ❓ Pertanyaan #2`, `#3`, dan seterusnya di dalam berkas topik tersebut.
3. **Tidak masuk ke `08-Prompt-History/`:** Seluruh pertanyaan belajar pada mode ini dicatat di sini, bukan di riwayat prompt.
4. **Kepatuhan Referensi:** Setiap rujukan paper atau sumber wajib berasal dari berkas terverifikasi (misal `references.bib`, `04-Literatur-Review/`, atau dokumentasi resmi).

Setiap berkas di folder ini akan otomatis muncul pada tabel **4. Tanya Jawab & Diskusi Belajar** di [[00-Index-Catatan]].
