# 💡 Subfolder: 03-Sintesis-dan-Ide

Subfolder ini dirancang sebagai wadah bagi Anda untuk mencatat:
1. **Sintesis Lintas Paper:** Menghubungkan temuan dari 2 paper atau lebih (misal: menggabungkan representasi sirkumpleks Russell dengan teknik dynamic alignment atau transformer HuBERT).
2. **Kilas Ide & Hipotesis Eksperimen:** Catatan spontan mengenai ide formulasi bobot metrik transisi, penanganan boundary jump, atau skema playlist reranking.
3. **Persiapan Mental Model & Sidang Sempro:** Catatan persiapan argumen pertahanan proposal, intisari jawaban atas kemungkinan sanggahan dosen penguji, dan analogi penjelas.

Setiap catatan baru di folder ini akan otomatis terdata di tabel **3. Sintesis & Ide Kreatif** pada [[00-Index-Catatan]].
